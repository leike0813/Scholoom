# UI 原型

Scholoom 工作台布局的静态可交互原型，无构建依赖。

浏览器直接打开 `index.html` 即可预览。右下角"原型控制"条（不属于产品设计）提供：

- 切换深/浅色主题；
- 折叠/展开左区、右区（也可点各自边缘的箭头按钮，或按 `Ctrl/Cmd+B`、`Ctrl/Cmd+Alt+B`）；
- 展开/收起 Agent（也可点击 dock 左侧 transcript 区域展开，`Esc` 或 overlay 右上角按钮收起）。

tab 组 A 头部的"向右拆分"按钮演示拆分，组 B 头部的按钮演示合并回来。

各状态的验证截图（1440×900，浅色/深色、Agent 展开、左右区折叠、窄窗口 dock 截断）见 [../screenshots/](../screenshots/)。
