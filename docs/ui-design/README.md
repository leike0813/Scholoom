# Scholoom 工作台 UI 初步设计

> 本设计的骨架部分（三区布局、Agent 面板双形态、tab 组、主题 token、防挤压）已在 `apps/desktop` 工作台实现，见 [工作台外壳交付](../../openspec/changes/archive/2026-10-15-establish-workbench-shell/delivery.md)。本文仍为各 tab 内部界面与后续组件的设计依据。

本文是 Scholoom Agent 工作台的初步界面设计，视觉与结构参考 `references/Codex-UI-Reference-Atlas.pdf`（Codex 官方界面图册及编者观察），关键色值与结构经官方截图像素取样核对。术语沿用 [CONTEXT.md](../../CONTEXT.md)。

配套可交互原型见 [prototype/](prototype/README.md)，无构建依赖，浏览器直接打开 `prototype/index.html` 即可预览；各状态验证截图见 [screenshots/](screenshots/)。

## 设计原则

图册第 18 页给出的四条取舍，落到本项目后作为设计原则：

1. **先搭稳定骨架。** 三区布局长期不变，窗口缩放、主题切换、Agent 展开/收起都不移动骨架元素，让用户依靠空间记忆找到会话、输入器和发送动作。
2. **让状态和对象相邻。** 会话的运行状态贴近会话行，任务的审批状态贴近任务行，产物入口紧贴对应结果，不靠颜色单点表达，也不让用户跨区域寻找。
3. **把输入与上下文一起设计。** composer 保留文本、发送和当前执行上下文（模型、权限、工作区），次要配置按使用频率折叠。
4. **统一主题的语义角色。** 先定义语义色（背景、浮层、正文、次级文字、状态色），再映射浅色与深色两套主题，组件结构在两套主题下完全一致。

## 布局结构

三区骨架，左右区可折叠为图标轨：

```
┌──────────┬─────────────────────────────────────────┬──────────┐
│ 左区      │ 中间区                                   │ 右区      │
│ ┌──────┐ │ ┌─Tab 组 A──────────┬─Tab 组 B────────┐ │文件/材料/任务│
│ │操作菜单│ │ │ 文献库│阅读器│编辑器 │ │ 交互预览       │ │ ┌──────┐ │
│ └──────┘ │ │                   │ │                │ │ │当前页签│ │
│ ┌──────┐ │ │                   │ │                │ │ │      │ │
│ │会话列表│ │ │                   │ │                │ │ │      │ │
│ │      │ │ ├───────────────────┴─┴───────────────┤ │ │      │ │
│ │      │ │ │ Agent dock（折叠态）                 │ │          │
│ │      │ │ │ tool(固定顶部) │ composer(精简)      │ │          │
│ │      │ │ │ agent 消息(截头留尾)│                │ │          │
│ └──────┘ │ └────────────────────────────────────┘ │ └──────┘ │
│ 内核状态  │ 执行状态                        通知摘要 / 数量        │
└──────────┴─────────────────────────────────────────┴──────────┘
```

- **左区**（默认 260px，可拖拽 220–360px）：顶部操作菜单，中部项目一级、Agent 会话二级的导航树，底部内核状态。折叠后剩 48px 图标轨，菜单项与会话入口保留为图标。
- **中间区**（占满剩余宽度，最小 480px）：tab 式多功能交互区 + 固定在底部的 Agent 面板。tab 组最多横向两组，通过 tab 组头部的"向右拆分"按钮把当前 tab 移入新组；组内无 tab 时自动合并。文献库、阅读器、编辑器、交互预览等都以 tab 形式存在；文件编辑与 Markdown 预览见下文，文献与交互报告内页随对应能力细化。
- **右区**（默认 300px，可拖拽 260–420px）：文件、材料、任务三个页签共用辅助面板。折叠后剩 48px 图标轨。

没有独立的全局顶栏。窗口标题栏只放窗口控制；连接状态、设置入口都在左区，参考 Codex 把工作区内的层级压到最少。

### 全局状态栏

中间区与右区下方共用一条固定单行状态栏，与左下内核状态区使用同一 `--statusbar-h`（40px），上下边线对齐。左区保持全高；左区折叠时图标轨底部保留同高空段。Agent dock 与 overlay 均位于状态栏上方，右侧面板和拖拽柄止于底栏上沿。背景与左下状态区使用同一 surface 和发丝分隔线。

执行状态常驻左侧，通知入口显示最高优先级摘要及数量，点击向上打开限高可滚动的详情层，包含全部当前通知和原有操作。错误优先，其次为需用户处理事项及普通信息；同级保持来源顺序。无通知显示零计数及空态。长文字在单行内截断，通知入口与数量保留；两套主题中图标、文字、焦点和错误均可辨。Esc 优先关闭详情并归还焦点，不同时收起 Agent。全局提示只在底栏及详情中呈现，局部表单、阅读和编辑反馈仍贴近对象，成果仍在内容区。

项目信任使用居中确认弹窗，提供信任、受限模式和取消。状态栏仅在当前项目待确认或受限时显示独立状态入口，点击打开同一弹窗，不计入普通通知；失败留在弹窗。新建或添加项目及旧项目首次确认沿原流程询问，明确选择受限后普通重开不反复弹出。

状态栏通过工作台实例内的标准条目接口接入，内置执行、通知、信任与后续组件共用注册、更新、显隐和释放机制。条目声明文字、受控图标、提示、左右位置、优先级和可访问名，动作单独适配；主题及尺寸由工作台统一呈现。贡献者卸载或工作台销毁时清理，展示描述为纯数据，供未来插件桥复用。

### 防挤压约束

窗口与各区都有最小尺寸，宁可出现滚动或截断，也不把布局挤坏：

- 窗口最小 960×600；小于最小宽度时整体横向滚动，不压缩各区。
- 左区最小 220px，右区最小 260px，中间区最小 480px，单个 tab 组最小 320px。
- dock 内 composer 最小 300px，transcript 不设最小宽度——宽度不足时 transcript 内文本截断，composer 保持可用。
- 窗口收窄时按频率折叠次要内容：先隐藏 composer 环境行（<1100px），再收窄 tab 标题，最后才是文本截断。输入框、发送按钮、状态灯永远保留。

## Agent 面板双形态

Agent 界面（transcript + composer）固定属于中间区，有折叠和展开两种形态，是会话的一等入口。

### 折叠态（dock）

dock 占据中间区底部整宽，默认高度 180px，可拖拽上沿在 120–320px 之间调整。中间区的主要空间仍留给交互 tab。

```
┌─Agent dock─────────────────────────────────────────┐
│ transcript（左，约 60%）      │ composer（右，约 40%） │
│ ● Ran search_library(...) ↵   │ ┌─────────────────┐ │ ← tool 消息固定在顶部
│   已完成初筛：9 篇候选文献…    │ │ 输入研究指令…     │ │
│   （agent 消息多行，截头留尾） │ │ [权限] [模型▾] [强度▾] [↑]│ │
│                               │ └─────────────────┘ │
└──────────────────────────────────────────────────────┘
```

- transcript 只呈现**最新一条 tool 消息 + 最新一条 agent 消息**，随执行滚动更新：
  - **tool 消息固定在 dock 顶部**，不随 agent 消息长度改变位置：单行，较小字号（12px），等宽字体，超长省略号截断，行首带状态指示灯（运行中绿、待审批黄、失败红）；
  - agent 消息占据 tool 消息下方的剩余高度：正文样式（衬线），多行，超出可用高度时**截断头部、显示尾部**——最新消息永远可见。
- composer 为精简版：多行输入框；配置行左侧为权限只读段（超长截断）与模型／推理强度聚合入口，dock 中聚合入口只显示图标，右侧固定取消／发送动作；点击聚合入口向上弹出小弹层，同时列出模型与推理强度两组单选。
- 点击 dock 内 composer 以外的任意位置，展开为 overlay。hover 时 transcript 区域给出可展开的视觉提示（cursor + 背景微变）。

### 展开态（overlay）

overlay 以浮层形式占满整个中间区（不遮挡左右区），布局回到 Codex 式传统会话界面：

```
┌─overlay（覆盖中间区）───────────────────────────────┐
│ 会话标题 · 模型            ⠿ 操作    [收起 ✕]       │
├────────────────────────────────────────────────────┤
│              用户消息（右对齐浅灰气泡）               │
│ agent 正文（整宽，衬线，内联链接指向材料/产物）        │
│ Ran git diff -- Views\MainPage.xaml …  （淡色单行）  │
│ Ran dotnet build QuickEdit.csproj  for 13s          │
│ ─────────── Worked for 6m 40s ───────────          │
│ agent 结果段落                                       │
│ ┌─产物卡片───────────────┐                          │
│ │ 1 个研究记录已更新  查看│                          │
│ │ research-notes/x.md +86│                          │
│ └────────────────────────┘                          │
├────────────────────────────────────────────────────┤
│ ┌─composer───────────────────────────────────────┐ │
│ │ 输入研究指令…                                    │ │
│ │ [权限]  [模型 · 推理强度▾]         [取消] [↑] │ │
│ │─ ⌘ 工作区▾   本地执行▾   项目▾  ─(独立色条)──── │ │
│ └────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

- 消息流组件（与图册"执行记录"页一致）：user 消息（右对齐浅灰气泡）、agent 正文（衬线）、淡色单行 tool 记录、"Worked for Xs" 轮次分隔线、产物/变更卡片紧贴结果段落。
- composer 三层：文本输入层；配置行（左侧权限与显示当前“模型 · 推理强度”的聚合入口，右侧固定取消／发送动作）；环境行（工作区、执行位置、项目上下文）。环境行是 composer 盒内底部的独立色条，与输入区用发丝线分开（取样自官方截图：输入区白底，环境条 #f5f5f5）。
- 关闭方式：Esc、右上角收起按钮。overlay 打开时焦点进入 composer 输入框，关闭后焦点回到 dock。
- overlay 不覆盖左右区，用户在长会话中仍可直接切换会话、查看文件树和任务列表。

## 组件规格

### 项目与文件工作台

左区同时驻留最近项目及普通会话，以项目为一级、会话为二级呈现。项目行显示目录末级名，整行折叠/展开会话列表，折叠状态分别以关闭／打开的文件夹图标表示；行尾依次为“管理项目 …”扩展按钮和加号新建按钮，普通会话同样提供；新建明确归属该行项目。菜单展示实际目录路径，以紧凑图标条目提供“打开项目”和经分隔的“从侧栏移除”，移除继续确认；不放置新建或名称表单。菜单按视口定位，支持 Esc、方向键和焦点归还。项目名称始终取目录名，旧别名不参与显示；用户可在文件系统中改名后重新添加。“添加项目”是左区顶部动作之一，打开居中弹窗，内含“打开项目”与“新建项目”两种模式：打开只选择目录，项目名取目录最后一级；新建先选择父目录，再输入新文件夹名称。Electron 使用系统目录选择器；浏览器调试宿主经内核目录浏览 RPC 在弹窗内选择，不提供手填项目路径。成功后选择新项目并清空其会话选择。设置打开中间区真实设置页，复用模型、授权和备份，并集中管理归档会话。真实首页默认没有占位 tab，空态提供项目入口；样例显式注入外壳演示内容。移出列表前必须确认，并明确说明只改变最近记录，不删除目录或停止执行；`application` 不提供移出入口。选择会话同时切换所属项目。各项目文件标签组和右栏恢复自身内容，共同文献库、设置和材料阅读器跨项目保留。新建或添加提交前弹出信任询问，提供“信任项目”“以受限模式添加”“取消”；受限项目允许人工浏览编辑，但不能运行 Agent。旧项目首次进入重新询问，设置中只提供一个“信任项目”选项，自动备份单独设置。

右区文件树按需展开并分页，目录优先、名称自然排序。标题工具栏提供新建文件／目录、刷新和全部折叠，回收站在树下展开。行内仅保留名称、类型图标、展开箭头和材料状态，操作经共享右键菜单或键盘进入。新建、重命名使用单行输入，Enter提交、Esc取消，错误贴近输入。新建位置为所选目录或所选文件父目录，根目录也提供入口。新文件创建后进入编辑器，新目录和重命名完成后聚焦对应树行。回收先确认目标范围，回收站显示原位置与恢复操作，冲突可填写其他位置；未保存草稿仍归原文件身份。

树的焦点、选择和会话材料附加分别表达。方向键导航与展开收起，Home/End到首尾，名称键入定位已加载行；Ctrl/Cmd增减选择、Shift范围选择，Ctrl/Cmd+A仅选择已加载展开条目。F2重命名，Enter固定打开，复制／剪切／粘贴和回收均提供菜单替代。右键或Shift+F10打开同一菜单，保留已选范围，Esc归还焦点。多选操作不批量打开文件，材料附加放入菜单，已附加文件以回形针提示。

拖拽默认移动，复制修饰键切换复制；目标目录高亮，悬停展开、边缘滚动，根目录可接收。文件剪贴板在同一内核项目切换间保留；系统文件与目录经选择或拖入复制，不改写系统源。操作区展示进度、取消、冲突和未知回执核查。目录同名递归合并，子项冲突可跳过、保留两份或确认替换；替换先回收原目标。跨项目剪切完整成功才回收源项，源项目保留原历史和草稿。

单击文件在当前活动组临时打开，每组一个临时tab，以斜体标题表示；双击文件或tab、Enter打开、编辑和并排查看后固定。未保存草稿固定保留。Markdown的源码／预览模式与临时tab状态分开；激活文件时树定位当前身份，只读取祖先与相关分页。项目切换保留展开、选择、滚动和tab状态。树使用固定行窗口化，仅渲染可见行及有限overscan；范围文件监听只刷新相关目录与文档。

项目与文件表单采用界面字体和紧凑纵向间距；输入框使用正文底色、强分隔边框和小圆角，两套主题一致映射。操作按钮有明确内边距、悬停与禁用态；源码／预览工具栏沿同一按钮样式，文件树行保持紧凑。目录缩进使用4px间距基准的三倍。

同一文件的源码与 Markdown 预览共用草稿；工具栏提供源码、预览、并排，默认源码，跨项目保留本页 tab 状态。并排使用既有最多两个 tab 组。预览说明未保存、更新中和旧结果状态；Agent 改动遇到草稿只提示磁盘变化。表格和代码在内容区横向滚动，图像不撑破列宽，公式使用本地字体。渲染使用语义 token，任务列表及未实现文献内容继续沿各自能力接入。

Markdown 支持本地栅格图片与数学公式；远端图片显示未加载提示，原始 HTML 不执行。图片不可用不遮挡正文。相对链接经文件 tab 打开，外链只在用户点击后打开受控协议。焦点、状态与按钮可访问名在双宿主保持一致。

### 基础 Agent 执行反馈

工具记录使用真实调用名与状态：执行中、完成、失败、结果未知。dock 保持最新工具单行，状态灯带文字可访问名；失败红色，未知使用次级文字，执行中绿色并带文字区分完成。工具记录不重复占用 Agent 正文区域。overlay 中每条工具记录使用原生可展开详情，摘要为调用名和状态，展开后显示等宽输入与结果预览；各上限 16,384 个 UTF-16 单元，截断时明确提示。详情默认收起，展开内容在卡片内滚动，避免撑开消息流。

两个输入器共用当前项目、模型、推理强度和项目信任状态说明。模型与推理强度经同一聚合入口设置：overlay 入口显示当前“模型 · 推理强度”，dock 入口只显示图标并以可访问名给出当前值；弹层内两组单选，各含“跟随默认”。选项只来自内核下发的 provider 目录；设置页保存应用默认，composer 保存会话级覆盖或“跟随默认”。所选模型不支持推理强度时禁用该组并说明原因，已有偏好保留。信任状态只显示当前已保存决定；连接或当前选择尚未就绪时明确提示，不展示另一项目的旧权限。切换失败保留快照中的当前值并原地显示可重试错误，错误提示不挤压发送动作。配置行不提供“继续执行”按钮：取消执行后由用户发送新的明确指令，内核 resume 能力不经工作台按钮暴露。环境行在窄窗口可隐藏，但模型与权限保留在配置行。

新建会话等待期间，输入暂时禁用并提示正在创建；结果返回后启用新会话的独立草稿。创建失败保留原草稿，等待期间用户切换会话的选择不被迟到回执覆盖。

会话成果入口紧贴所属执行的 Agent 结果消息，使用紧凑行显示文件名、路径及“打开成果”；没有独立的顶部成果区或消息流末尾汇总区。dock 保持进展摘要，展开会话后访问成果。消息与成果按执行标识关联；尚无正文结果时归入同执行的工具结果，历史记录只使用已明确的执行关联，分页未加载的消息不挂到其他回复上。保存、登记及待核查反馈统一进入状态栏通知详情，待核查项保留“核查并补齐”；失败留在详情中，可重试。打开沿共同文件 tab，收起 overlay 使文件可见；指令草稿、附加材料和会话接收者保持原值。文件缺失或权限失效由文件页显示错误，登记结果待核查不因点击打开而改写。

本节对应 [执行工作台变更](../../openspec/changes/archive/2026-10-15-complete-agent-execution-workbench/proposal.md)。科研方法、插件、任务审批和受管程序界面沿各自能力交付。

### 科研写作编辑器

文件标签工具栏提供源码、可视编辑、轻量预览、完整排版及导出入口，沿现有最多两个标签组展示；源码与可视模式切换不隐式保存。QMD／Markdown 提供可视编辑，LaTeX 保留原生源码和编译 PDF。模式与预览格式分别表达，临时标签状态独立于编辑模式。左右栏和 Agent dock 保持用户原有选择。

源码区使用等宽字体、行号、语法高亮、折叠、括号提示及多光标，提供查找／替换、跳行、撤销／重做和 Ctrl/Cmd+S。关键字、字符串及数值分别使用两套主题中的语法语义颜色，链接使用 accent，注释使用次要文本色。底部状态行显示当前光标、语言及缩进；未保存和保存中状态贴近文件路径。学术可视工具栏按结构、格式及插入操作分组，公式、引文、表格、图像与交叉引用使用工作台对话框及标准格式；无法安全表示的内容保留源码入口和原稿。

轻量预览读取当前草稿并明确未保存状态。完整排版读取已保存版本，打开预览及保存后更新当前格式：QMD 默认 HTML，选择 PDF 时更新 PDF；DOCX 和其他格式手动导出。编译操作区显示排队、执行、失败及取消状态，日志和诊断按需展开；失败时保留最后成功产物并说明其版本。缺少工具时保留编辑区，提供缺项与重试入口。

源码、可视正文和排版区各自滚动，不扫描整个工作台 DOM。HTML 展示使用受限容器，排版纸面在两种主题下均为白底，保留产物自身的正文颜色；PDF 复用共同查看器，导出路径沿现有文件冲突处理。编辑工具和输入框使用工作台主题颜色。新增样式只引用 styles.css 中两套主题共同映射的语义 token；关键按钮、模式、编辑区及状态都有可访问名。

### 会话管理与消息阅读

左区各项目组分别呈现其活动会话，滚动接近底部时沿内核游标追加加载，不设“活动／归档”切换与翻页控件。查找会话由左区顶部动作打开居中弹窗（结构参考 Codex 搜索弹窗）：跨最近项目全局搜索，空查询显示最近会话，输入防抖后查询；结果行显示状态、标题、项目名、归档标识与相对时间，选择后切换到对应项目与会话；筛选不切换当前会话接收者，迟到响应不覆盖新查询结果。归档会话集中在设置页按项目管理与恢复；归档当前会话后由状态栏通知详情提供恢复入口，不替代设置页集中管理。会话行保留独立选择按钮，“重命名”与“归档／恢复”两个条目移入整行右键菜单（同时支持 Shift+F10／ContextMenu 键），不再有行尾“管理会话 …”入口；选择“重命名”后会话行原地变为输入框，Enter 保存，Esc 或失焦取消，失败错误留在行下方；运行、排队或取消中的会话禁用归档并说明原因。归档或恢复失败时错误保留在操作发生的菜单内，设置页恢复失败留在对应行内；当前会话恢复失败在状态栏所属通知内显示错误。新会话以首条受理指令命名，可手动修改。归档当前会话后保留历史及草稿，输入与模型／推理强度选择禁用，显示恢复入口；恢复不自动执行。顶部、折叠左轨和中间空态均不提供全局新建入口；新建使用各项目行按钮。会话图标直接打开同一查找弹窗。

overlay 的 Agent 正文支持 Markdown、表格、代码与公式；用户消息仍按纯文本展示。受理状态、附加材料及实际使用材料是正文外的紧凑事实行，材料可打开。正文和代码块各提供可键盘操作的复制按钮，复制原始文本并在失败时反馈。材料和相对文件链接打开同一文件 tab 并收起 overlay，保留会话与草稿；相对链接以项目根为基准，路径按 URI 解码并分离片段后核对项目边界，外链经明确点击打开，消息图片显示替代说明，原始 HTML 不执行。dock 继续显示纯文本尾部。归档、错误及待核查指令等通知统一在状态栏详情中展示；dock 与 overlay 使用同一来源，长通知不挤出输入器。

消息解析只面向已加载的可见正文，复用文件预览的共享 Worker 调度，按对象合并待处理版本。旧结果不覆盖新正文，失败保留原文；代码及表格在消息内横向滚动，不撑破列宽。组件沿用现有语义 token、浅深色映射及焦点规则。

### 左区

**标题行**：左侧 Scholoom 标题，右侧依次为主题切换按钮与折叠按钮；折叠按钮使用左侧栏图标，主题按钮可访问名保持“切换主题”。

**操作菜单**（顶部）：查找会话、添加项目、文献库、设置。其中查找会话与添加项目都打开居中弹窗。行结构：细线图标 + 文字，整行可点。

**项目与会话树**：项目行高 30–32px，结构为文件夹图标（折叠时关闭、展开时打开）+ 显示名（超长截断，悬停显示完整名）+ 行尾扩展菜单 + 新建会话按钮。会话行嵌在所属项目下，行结构为状态灯 + 标题（超长截断，悬停显示完整名）+ 相对时间；操作不占行尾入口，整行右键（或 Shift+F10／ContextMenu 键）打开同一上下文菜单。状态语义贴近条目：运行中（绿灯呼吸）、待审批（软绿 pill，同 Codex "Awaiting approval"）、未读（蓝点）、失败（红灯）。选中行整行底色（取样 #e8e8e8）且标题加粗。会话列表滚动加载，渲染范围限定在已加载页内，避免高频状态更新重绘全部会话。

**内核状态**（底部）：固定单行，仅 LED 状态灯 + 一行状态文字（已连接 / 重连中 / 未连接），超长截断不换行；实例标识、错误详情、“重试连接”“查询状态”移入 hover/focus 弹出的详情层。工作台不提供“停止内核”入口；停机保留在 CLI／RPC，工作台收到停机通知后如实呈现受理、结果未知、查询与重试。状态源仍为 `WorkbenchConnection`（见 `apps/desktop/src/renderer/src/workbench/session.ts`），位置在左区底部——Codex 把 Settings 放在同样的位置。

### 中间区

**tab 头**：图标 + 标题 + 关闭按钮，单行不换行；激活 tab 底部 2px 强调线并接入正文底色，非激活 tab 文字降一级。

**tab 组**：头部右侧放"向右拆分"按钮，把当前 tab 移入新组；两组时第二个组的头部提供"合并回去"。不做拖拽拆分（初步设计阶段的有意省略，后续按实际使用反馈再议）。

**空态**：无 tab 时参考 Codex 新对话空态——居中标题（带入当前工作区名）+ 常用入口建议（打开文献库、新建稿件、最近文件）。

### 右区

**文件树**：工作区材料的层级树，行高 28px，缩进 12px/级；当前被 tab 打开的文件加粗。

**任务列表**：研究任务行，结构与 Codex 任务列表一致——状态 pill（进行中 / 待审批 / 已完成）贴近任务名，右侧相对时间；选中行整行底色。大量任务时同样限定渲染范围。

### 状态灯与 pill 语义

| 语义 | 浅色 | 深色 | 用法 |
|---|---|---|---|
| 运行中 | 绿点（呼吸） | 同 | 会话、tool 消息 |
| 待审批 | 软绿 pill（#d1e9dc/#1a7f47） | 暗绿 pill（#23413a/#7fd6a5） | 会话、任务 |
| 未读 | 蓝点 | 同 | 会话行 |
| 失败/错误 | 红点 | 同 | 会话、tool 消息、内核状态 |

待审批沿用 Codex 的软绿 pill 而非警示黄：它是正常的流程状态而非异常。状态不只靠颜色：pill 带文字，灯配 `aria-label`。

## 设计 token

语义角色先行，两套主题分别映射。色值经官方截图像素取样（浅色侧栏 #f3f3f3、正文 #ffffff、选中行 #e8e8e8、正文文字 #262626、待审批 pill #cee5d7；深色正文 #181818、待审批 pill #23413a），个别明度做了可读性微调。

| `--bg` | `#ffffff` | `#181818` | 中间区正文背景 |

| `--border-strong` | `#d9d9d9` | `#3d3d3d` | 输入框、composer 边 |
| `--text-primary` | `#262626` | `#e8e8e8` | 正文 |
| `--text-secondary` | `#6e6e6e` | `#9a9a9a` | 次级文字、tool 记录 |
| `--text-tertiary` | `#a3a3a3` | `#6e6e6e` | 占位、时间戳 |

字体：界面 `system-ui` 栈；**agent 正文与文档内容用衬线**（`Charter, Georgia, "Songti SC", "Noto Serif CJK SC", serif`，Codex 的 agent 正文为衬线，学术场景也契合）；tool 记录与代码 `ui-monospace` 栈。界面字号 13–14px，agent 正文 14.5px，tool 记录 12px，行高 1.5–1.6。

圆角：行项与按钮 6px，卡片 8px，composer 14px，pill 999px。间距以 4px 为基，常用 8/12/16/24；左区项目与会话行高使用 `--row-h`。分隔优先用底色差，其次发丝线（1px `--border`），避免粗边框。

焦点：`:focus-visible` 2px accent 描边，offset 2px，两套主题下都必须可见。

## 交互规则

- Agent 展开：点击 dock 内 composer 以外任意位置。
- Agent 收起：Esc 或 overlay 右上角收起按钮；收起后焦点回到 dock。
- 左区折叠：`Ctrl/Cmd+B`；右区折叠：`Ctrl/Cmd+Alt+B`。
- 拆分：tab 组头部"向右拆分"；`Ctrl/Cmd+\` 对当前 tab 执行同样动作。
- 所有行项目（会话、任务、文件）保留明确点击区域与键盘焦点，可操作元素都能 Tab 到达。

## 已知留白

### 本地题录库

文献库入口在现有左区菜单启用，并在中间 library tab 呈现，不切换当前会话。tab 顶部为题录查找、集合筛选与上一页/下一页（每页25）；列表行显示题名、版本与“附件未取得／分析未生成”，可选择查看。详情呈现 CSL JSON 题录、稳定身份、来源、修订号、标签、集合与关联版本；修改只在明确保存时提交，冲突保留草稿并提供重新读取。

手动建项提供题名、DOI与版本标签；CSL JSON 导入提供粘贴区及本机文件选择，选择文件只读取用户选中的 JSON 文本。提交后显示批次引用、逐项创建/复用/失败及冲突字段，中断有明确继续入口。集合可命名及指定父集合，同一条目可多选集合，移出只改变分组。库读取、写入、发送到模型与自动备份在可展开的“文献库授权与备份”中分别设置；备份列表可恢复至新独立配置目录，显示结果路径。

所有操作沿现有 btn、project-controls、pane 等样式及语义 token，不新设颜色或布局；表单有可访问名，失败使用 role=alert，批次结果与空态可读。元数据编辑和导入文本在范围刷新时保留；详情、列表和批次均有界读取，库失效通知只触发当前库范围重读。样例没有真实客户端时保留占位。

更正草稿按库和条目保存读取时的修订号；刷新页面后继续编辑仍检查原修订号。保存等待期间禁用再次保存及显式重读，但可继续输入和切换条目；成功回执只推进对应草稿的修订号，保留后续编辑，不改写另一条目的画面。

本地材料摄取位于同一库 tab 的可展开表单，输入本机绝对路径（每行一份，最多100份）、用途、版本及托管方式；默认托管，外链明确由原位置提供文件。全库表单为每份文件建立待核对的文件名题录，在所选题录详情内则添加正文或补充材料等附件。成功与失败沿共同摄取批次显示，题录由文件名生成时标明待核对。

题录行区分“附件未取得”和“已有附件登记”；详情按页列出附件名称、用途、托管/外链及实际可读、缺失、变化或不可用原因。刷新只检查所选题录当前页，下载仅在明确点击后按段读取，失败保留原条目。外链可显式输入新路径并点击“重新定位”，内容不同则保留旧版本及错误；不提供跨版本替换。附件操作不改变会话接收者或题录编辑草稿。

备份列表区分仅题录数据库与题录及托管材料，缺项按附件引用列出原因；外链未复制明确为外部依赖。恢复仍只创建新独立配置目录。

### PDF 阅读与共同记录

题录附件详情提供“打开 PDF”，以附件与材料版本打开已有 reader tab，保持当前会话和指令草稿。tab 内使用 EmbedPDF 的翻页、缩放、搜索与文字选择，阅读运行资源本地提供；主题映射现有语义 token。原材料缺失或变化时显示对应原因，仍允许查看已存阅读成果。

阅读成果在 tab 内可折叠区域按页列出，显示书签／高亮／笔记、作者、摘录、说明和保存状态；创建者为用户或具体 Agent 会话，解释不混作原文。每页25条，上一页／下一页只读取当前材料。点击有位置的记录导航到原版本页面；材料不可用时禁用定位，并保留摘录。选区提供明确保存高亮的动作；书签保存当前页，笔记可针对整份材料，未保存选区不表示已创建批注。

附件详情也可打开同一材料的阅读记录，以便在阅读窗口关闭或材料失效时管理说明。每次只展开所选附件的记录，提供独立笔记创建、说明更正、分页旧修订和明确移除；不因展示附件列表自动查询所有附件的记录。记录面板和阅读器沿同一共同模块，不另建持久化路径。

说明编辑使用既有表单、按钮和 alert 样式。创建／更正／移除均明确提交，保存核对所读修订，失败保留文本；冲突显示“重新读取”入口，重读前可复制草稿，不静默合并。更正可查看分页旧修订；移除只影响阅读记录。说明草稿按库、附件、材料版本及记录身份保存；切换会话、收展 Agent 面板和范围刷新不丢失，迟到回执不能覆盖后续输入。库通知不重建阅读器，关闭 tab 释放 SDK 和临时字节资源。

### EPUB 与 HTML 快照阅读

附件详情按后缀提供“打开 EPUB”或“打开网页”，沿同一材料版本 reader tab，不切换会话。章节工具栏提供分页章节选择、上一段／下一段和搜索，各项横向排列并随可用宽度换行；搜索结果按页显示章节与摘录，明确是否覆盖全书，点击定位同版本文字区间。正文采用既有语义 token 排版标题、段落、列表、表格、链接和栅格图片；缺资源显示替代说明，不加载原书样式或外网资源。

文字选区在当前正文片段内转换为共同字符区间，明确点击“保留选区”才进入共同阅读记录草稿；“添加书签”记录当前章节和片段起点。记录列表显示章节位置，定位时读取对应片段并投影当前页记录，不全书读取。说明、冲突、未知回执及会话草稿沿共同阅读面板；关闭 tab 释放自有资源。章节、搜索和记录均可用键盘操作，正文区提供独立可访问名和加载／错误反馈。
