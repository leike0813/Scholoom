## Why

PR #10 已补齐 CI 写作工具，但真实三平台回归仍暴露 BibTeX 夹具语义、目录别名比较、Windows 创建候选同步与打开存储时移动目录等问题。现有实现将真实路径与未规范化根比较，既误拒绝合法产物，也漏排私有配置；创建候选以只读句柄执行同步在 Windows 失败。本变更基于最新 dev 23e68c8 修复这些根因，保持原安全检查和断言，不修改 locale、不跳过测试，不实施库 UI。

## What Changes

- 路径范围检查在实际访问处使用同一真实根，合法目录别名可读取，越界与私有目录仍拒绝。
- 创建候选以可写句柄同步，保留原 fsync、原子发布及未知效果核查。
- 测试使用语义明确的 BibTeX 大小写保护，目录断言比较真实位置；项目移动先释放所属存储，仍验证旧执行实例失效。
- 按实际 CI 日志修复必要的子进程夹具路径问题，记录平台证据与剩余失败。

## 完成判据

- 别名根的合法读取、越界拒绝和私有目录保护均有真实文件系统回归；拒绝创建不留下目录。
- 原有写作、文件创建、旧实例拒绝及崩溃恢复断言保留并运行；Windows 文件同步和命令查找以真实 CI 为证据。
- 全仓静态检查通过，交付记录区分三平台实际结果与未验路径；提交推送并提供面向 dev 的可审查 PR。
