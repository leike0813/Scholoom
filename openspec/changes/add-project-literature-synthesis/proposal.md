# 变更提议

## Why

现有科研图注册、可信请求、任务输入快照及成果核查已提供共同接点，但生产尚无已注册的文献综合业务图；已有项目文本材料分析仍沿原 method/invoke 执行，不能代表库文献综合已交付。本变更沿 D01 已确认的路径，让用户从已有共同库材料出发，在项目中形成有来源依据的定向综合，并在补充材料后由新会话读取实际成果继续研究。交付需要同时证明真实取材、研究判断与过程保存、来源及成果可核查和后续修改，不能由执行结束、文件存在或固定夹具通过推定科研质量。具体图节点、回路及跨模块接口仍由主线结合并行调查确定，不沿用 D04 Q7 的未采纳候选流程。

## What Changes

- 增加由本项目源码维护的项目文献综合业务 Graph，复用科研图发现／请求、通用 harness 和领域接口。节点提示、方法及检查素材由本项目维护，保证必要的工作与等待由图落实，不以整份 Skill 指挥通用 Agent 代替业务流程。
- 以用户明确的研究问题、必要约束及指定或获授权的库材料范围为输入。校准路径按用户明确要求建立或采用项目研究任务；普通会话不因此自动创建任务或绑定任务。实际取材保留所属身份、材料版本、内容依据与读取深度，区分材料正常部分可用和必须暂停询问的读取异常。
- 在形成时保存项目自己的比较、采用／排除理由、报告、障碍及下一步，按原文件身份、保存依据及任务入口关联取回；库内容仍按指针读取，不复制为项目知识权威。保存、关联、执行与科研判断分别表达，失败或未知保留已成功成果和原操作身份。
- 让用户补充或补齐库材料后，在新会话通过普通消息要求续做；从任务、实际来源、已有过程与成果重建研究语境，说明新增材料的实际影响，保存更新理由及后续成果，不依赖旧聊天或临时文件。
- 沿已有文档视图展示、编辑和核查成果。具体节点与回路、材料解析及长内容的实际消费证明、科研 Agent 节点接法、任务续做关系和最小共享接口由后续规格／设计闭合，不能把当前完整文本检查的限制转写成 text-only 产品范围。

本次不包含活动报告执行器、线上检索／获取、以多 Agent 为前置的业务、库级知识写回、主题维护或用户自定义 Graph。独立复核若被用户或所选能力明确要求，仍须实际完成或报告未完成，不能静默省略。`scholoom.material-analysis` 的发现、正文、method/invoke 输入、历史尝试及原行为保持；不将旧记录补成新 Graph 记录，不默认引入 ResearchSpec 的 CC BY-NC 内容。

## 完成判据

以下是后续实现与验收的目标，本次仅交前两规划工件，不表示这些判据已通过。

1. 用户从真实项目／任务入口选择内建图及当前材料，在当前项目／库 read、send 和保存授权下启动实际执行。图身份、整体版本、真实执行引用与采用材料可核查；发现、查询、重启或迟到结果不自动开工。
2. 报告及可取回的过程共同回答研究问题，给出范围、纳入／排除理由、比较维度、有来源支撑的发现、冲突与条件、研究本身／材料覆盖／当前证据三个层次的局限、未决问题及下一步。结论须与实际读取的材料相符，不能把覆盖不足直接写成研究空白；呈现不锁定章节、节点数或固定表格。
3. 能核对实际来源身份／版本与读取结果，以及本次真实保存、读回和任务关联。已知材料条件、缺项、读取错误及待用户决定分别可诊断；撤权、身份／版本变化或必须询问的异常不能由缓存、同名来源或模型记忆替代。普通消息中的明确选择才可继续依赖相应来源的工作。
4. 首次报告和过程能通过已有文档视图读取、核查和编辑。保存冲突、关联未确认或未知效果不删除已保存成果、不重生成代替核查，不覆盖用户修改，也不把 run 完成映射为研究任务完成。
5. 在隔离样本中加入或补齐材料，新会话能够通过明确任务和现有文件发现研究目的、原依据及下一步，实际核对新增材料并保存其对判断的影响、修订或保留原判断的理由。核对真实后续文件与任务关系，而不只检查打开旧报告或生成交接摘要。
6. 受控外部模型仅用于机械接线与保护边界验证；真实材料、实际科研模型产物及内容评价须按后续明确的样本与判据另行核对。未真实运行和评价前，科研质量保持未验；执行状态、程序交付检查及 `researchAssessment: notAssessed` 不替代科研评价。旧材料分析行为继续可用。

## Capabilities

### Modified Capabilities

- `research-capabilities`：补充项目定向文献综合的内建业务图、真实取材与研究内容交付、材料异常等待及补充材料续做的可观察行为，复用已有可信请求、调用／尝试、停止与部分结果契约；不迁移旧材料分析入口。
- `research-tasks`：补充综合任务的来源／过程／成果保存及新会话补材料续做场景，保持原 TaskRef、入口文件、历史输入快照、强依据保存及关联权威。是否需要扩展共享字段由主线汇合调查后决定，本提议不预定 DTO。
