# 科研写作编辑器

## Why

现有文件工作台已经提供 CodeMirror、条件保存、草稿、文件监听和 Markdown 预览，但缺少日常源码编辑工具、学术可视编辑和人工编译导出链路。用户希望在既有工作台内完成类似 VS Code 的编辑操作，并直接写作 QMD、Markdown 和原生 LaTeX 工程。人工编辑与排版应独立于 Agent harness，同时沿用共同文件权威、授权和已有数据保护，避免出现另一套正文或保存机制。

## What Changes

- 提供源码编辑工具、常见科研语言、共享文稿状态与模式切换。
- 吸纳 Quarto 学术可视编辑模块，支持公式、引文、图表、交叉引用及未知内容保护；书目使用项目 `.bib`／CSL JSON。
- 新增独立 editor 能力与受管转换、编译、状态、取消、产物读取及导出入口。
- 草稿驱动轻量预览，保存驱动当前格式的完整预览；支持 QMD HTML／PDF／DOCX 及多文件 LaTeX PDF。
- 普通预览使用受控转换与已有结果，不运行科研代码、工程钩子或自定义可执行扩展；保留最后成功产物。
- 保留现有布局、文件树、最多两个标签组及 Agent dock，更新设计和开发说明。

## 完成判据

- 从真实文件树打开、编辑、切换源码／可视模式、保存并重新打开，文件与草稿一致，过期保存不能覆盖他人修改。
- 在不建立会话、不调用模型的人工组合中，从产品入口完成 QMD HTML／PDF／DOCX 和 LaTeX PDF，读取实际产物及对应版本。
- 连续保存、依赖变化、失败、取消、超时、缺少工具和内核退出均有可诊断结果；失败不能发布半成品或丢弃旧成功结果。
- 相关内核、转换、双宿主 UI、类型、构建和架构检查通过；交付记录区分实际验证、模拟边界及未验收平台。

## Capabilities

### New Capabilities

- `workspace-editor`：共享文稿、源码与学术可视编辑、书目与内容保留。
- `manuscript-rendering`：人工格式转换、受管编译、产物版本、取消和导出。

### Modified Capabilities

- `ui-workbench-shell`：编辑模式、编辑工具、完整预览及导出接入现有标签组。
- `module-runtime`：人工编辑及排版能力无需 harness，跨模块继续经共同 broker。
