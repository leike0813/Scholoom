## MODIFIED Requirements

### Requirement: 可独立组合的模块能力

系统 SHALL 支持不加载 harness 的文献管理、项目、文件操作、稿件转换、预览编译及导出组合，以及不加载工作台的 Agent 执行组合。普通领域操作 SHALL 不要求建立 Agent 会话或调用模型。科研运行能力 SHALL 通过通用执行能力接入，科研规则不成为人工基础操作的前置依赖。模块 SHALL 通过明确的公共导出及依赖接入独立测试，提取模块不要求携带整个应用实现。编辑呈现、项目文件权威及排版执行各自负责自身事实，跨模块操作仍经共同 broker。

#### Scenario: 人工组合不加载 Agent

- **WHEN** 宿主只装配文献、项目、编辑器和它们实际需要的基础能力
- **THEN** 已实现的题录、附件、阅读记录、文件操作及稿件编译导出可用，不为缺少 harness 禁用这些操作或创建会话

#### Scenario: 无工作台执行

- **WHEN** 调用方经共同入口向已授权会话发送研究指令
- **THEN** 无需启动工作台即可读取材料并保存成果，随后工作台查询到同一领域记录和实际文件
