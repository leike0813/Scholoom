# Spec Delta

## ADDED Requirements

### Requirement: 项目 HTML 正文的受保护保存

系统 SHALL 允许具备正文写入能力的项目 HTML 经共同资源保存入口核对稳定文件身份和实际读取依据后保存，保持原串行保存、并发保护及成果结果核查。HTML 可保存不授予其脚本运行权限；普通阅读视图继续使用安全结构，只有明确报告入口沿报告隔离契约运行。库附件和跨项目只读引用不得因此取得写入能力。

#### Scenario: 报告更新与普通安全阅读

- **WHEN** 已授权项目 Agent 按当前HTML依据更新报告，随后用户从普通HTML阅读入口打开
- **THEN** 保存结果经实际文件读回可核对，普通阅读仍不执行脚本，报告交互需使用明确入口

#### Scenario: HTML 保存期间替换或撤权

- **WHEN** 原HTML在保存临界区前被替换或有效写入资格被撤销
- **THEN** 旧保存被拒绝并保留原文件及候选，不因同路径或同内容替换而放行
