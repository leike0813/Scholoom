# Spec Delta

## ADDED Requirements

### Requirement: 可操作的全局题录库

真实工作台 SHALL 从现有文献库入口打开共同库 tab，提供手动建项、CSL JSON 选择文件/粘贴导入、批次逐项结果、有界查找、题录更正与集合/标签整理。查看库 SHALL 不切换 Agent 会话或丢失项目/会话草稿。附件未取得与分析未生成如实显示，不把题录当作可读全文。授权、失败、冲突和备份入口使用已有交互样式并可键盘操作。

#### Scenario: 在项目内浏览共同题录
- **WHEN** 用户带着指令草稿打开文献库，建项并导入批次
- **THEN** 可查询已保存题录和逐项结果，原会话与草稿保留；另一个客户端重读取得同一事实
