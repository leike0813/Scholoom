# 变更提议

## Why

现有共同文献阅读只支持 PDF，EPUB 与本地网页附件虽可摄取，却不能在工作台阅读，也不能由 Agent 取得解析正文。沿实施路线图 P4b 和初设 L-03／L-04，本变更补齐 EPUB 重排版及单文件 HTML 快照，复用现有附件身份、授权和阅读成果权威，使人和 Agent 可以从同一材料留下可接续的阅读记录。

## What Changes

- 增加 EPUB 2／3 重排版和 HTML 单文件解析、有界章节读取、全文搜索和受控栅格图片读取。
- 扩展共同位置为 PDF 或规范化文本区间，沿既有记录修订、未知回执核查及独立备份恢复保存。
- 在既有双宿主 reader tab 提供章节、搜索、选区、书签、高亮和笔记。
- 不接在线抓取、HTML 配套目录、原书 CSS／字体、固定版式、DRM 或跨版本自动定位。

## 完成判据

1. EPUB 2／3 与 HTML 样本经现有附件入口在浏览器和 Electron 阅读、搜索及保存记录，关闭重开仍可定位。
2. Agent 不打开阅读器也可读取同一正文和用户记录，作者、摘录与解释可辨。
3. 范围、资源、权限、取消、版本和恢复边界有实际验证，故障不阻塞库查询和后续合法读取，原材料字节保留。
4. PDF 回归、类型／架构／构建检查、规格验证及独立审查完成，delivery 如实记录范围。

## Capabilities

### Modified Capabilities

- `literature-reading`：共同 EPUB／HTML 取文、安全正文表示、文本位置及授权。
- `ui-workbench-shell`：共同附件阅读入口和文档阅读交互。
