# Spec Delta

## ADDED Requirements

### Requirement: 执行钉入实际模型配置

新建执行 SHALL 在创建时解析会话有效模型配置（会话覆盖优先、缺项回落应用默认），把实际使用的模型与推理强度（受支持时）写入该执行的持久记录，并对客户端可见。执行中追加指令 SHALL 沿用所属执行已钉入的配置；显式继续（resume）SHALL 沿用原执行配置，不重新解析当前默认。变更应用默认或会话覆盖 SHALL 不影响已创建或已排队的执行。没有新字段的旧会话与旧执行记录 SHALL 按继承当前有效配置兼容读取，不要求迁移。

#### Scenario: 追加与继续使用原配置

- **WHEN** 用户修改默认或会话覆盖后，向运行中的执行追加指令或显式继续已中断的执行
- **THEN** 追加与继续使用原执行钉入的模型与推理强度，新配置只作用于之后创建的执行

#### Scenario: 执行记录可核对

- **WHEN** 用户或客户端读取一次已结束的执行
- **THEN** 可见该次执行实际使用的模型与推理强度，与创建后发生的默认变更无关
