# Model Access

## Purpose

为独立科研内核提供可直接配置的 MiniMax M Plan 中国区模型、受保护的本机凭据以及项目材料发送授权，使真实执行、上下文压缩和重试复用同一接收方、授权及资源限制，避免密钥与研究材料通过其他路径外泄。

## ADDED Requirements

### Requirement: 内置连接与受保护凭据

系统 SHALL 内置 MiniMax M Plan 中国区连接，用户只需填写 API Key；已保存 key 优先于 MINIMAX_CN_API_KEY 环境注入。凭据 SHALL 加密保存并在本机自动解锁，仅提供写入与状态接口，不回读密钥；主密钥与密文 SHALL 受本机权限保护，不进入项目、会话、普通日志、项目备份或静态文件服务。缺失、损坏和权限错误 SHALL 可诊断且不覆盖原凭据。

#### Scenario: 重启独立内核
- **WHEN** 用户保存 key 后关闭工作台并重启内核
- **THEN** 内核可解锁凭据，状态仅显示来源及是否配置

#### Scenario: 环境注入
- **WHEN** 没有保存凭据且环境提供 MINIMAX_CN_API_KEY
- **THEN** 内核可直接调用模型而不把环境 key 写入磁盘

### Requirement: 项目授权与共同模型控制

内核 SHALL 分别核对项目读取、普通写入和向 MiniMax 发送材料的有效授权；范围内不重复确认，浏览及附加材料不扩大权限。模型调用与压缩 SHALL 共用有限超时、并发及限流，安全临时失败最多额外重试两次，参数、凭据和授权错误直接报告，不静默切换模型或端点。完整模型内容块 SHALL 用于后续工具轮次，缺失用量记为未知。

#### Scenario: 材料未授权发送
- **WHEN** 项目可读取但尚未允许发送到 MiniMax
- **THEN** 不发出包含项目材料的模型请求，返回缺少授权的状态

#### Scenario: 模型失败
- **WHEN** 凭据失效、额度受限或安全重试耗尽
- **THEN** 保留已保存成果、执行状态与必要错误，不改用其他接收方
