# 变更提议

## Why

已有共同文献权威和管理入口可以建项、摄取、按修订保存和恢复草稿，但人工更正仍依赖 CSL JSON，集合只作扁平筛选，列表选择按行号维护，题录选择没有进入已交付的工作台上下文工具。B 批需要把这些基础接线变成可日常使用的类型化编辑、集合导航与稳定选择，同时保留未知字段、现有授权、批次和异步草稿保护。生态身份与字段调查尚未交付，不能用原型的局部映射代替固定 Zotero 基线契约。

## What Changes

- 在现有 library tab 上提供类型化题录及有序创建者编辑；从完整 CSL 草稿修改明确字段，保留未知字段及未编辑的嵌套值。
- 将行索引选择改为库身份和条目身份上的主选／多选，支持有界集合导航、列表列配置和当前范围内的选择重建；详情继续惰性读取。
- 向现有连接所属上下文工具贡献真实题录选择，包含无附件条目；库浏览、翻页和附件打开保持原会话接收者与工作域。
- 保留原修订检查、历史、批次和授权；类型表单、JSON 视图共用一份草稿，冲突、重载及迟到成功／失败不能覆盖后续输入。
- 正式引用键仍由文献域掌握。本批不实现引用键生成、插件宿主、迁入、材料写回、批量更正、删除合并、高级搜索、笔记或报告。

## 完成判据

1. 隔离真实库中经双宿主入口收录、类型化更正并重启读回；未知 CSL 数据、创建者顺序、来源和历史保留，冲突不覆盖。
2. 集合导航、配置列、稳定主选／多选在分页、筛选、重排和切 tab 后没有身份串位；选择和编辑草稿独立于 Agent 会话。
3. 实际 `read_workbench_context` 返回来源窗口当前题录选择，覆盖无附件对象；断线、多窗口、撤权与版本变化有明确结果，不扩大读写或外发授权。
4. 不重复建设已归档公共基础；内部客户端、broker、SQLite、工作台和 harness 接线真实，外部模型允许受控响应。B 批通过仅表示本批完成。

## Capabilities

### Modified Capabilities

- `literature-catalog`：新增类型化无损编辑、集合导航与列、稳定主选／多选的行为要求，沿用现有管理与保存契约。
- `workbench-agent-context`：新增题录领域对当前上下文的贡献要求；共同连接、指令及显式材料生命周期继续沿原规格。
