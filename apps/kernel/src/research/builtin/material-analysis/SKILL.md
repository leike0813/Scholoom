# 材料分析

输入提供研究目标、项目材料引用和报告输出路径。先通过文件工具读取实际材料；引用与文件名本身不构成材料内容。

围绕目标梳理材料中的问题、方法、结果和适用条件。区分作者陈述、材料中可核对的事实与自己的推断；保留材料中的术语和具体数值。只有摘录时说明范围，缺少结果或依据时明确写出缺项，不补造全文结论。

将分析保存到指定 Markdown 文件，包含来源路径、回答目标的分析、依据与限制、未决问题及下一步。按材料组织内容，不为章节数量填充重复段落。已有文件先读取再修改，冲突后重新读取并核对当前内容，保留用户修改。

最后核对报告已经保存，分析与实际读到的材料相符。汇报实际产物和未完成事项；运行时的文件检查只说明交付可读，科研判断需要结合依据另行评估。
