# 暂不纳入依赖持续精确原文定位的功能

Labels: wayfinder:decision
Status: resolved
Assignee: Codex；主 Agent 与用户讨论（2026-10-13）
Parent: [产品与工程基础决策地图](../map.md)

## Question

科研对象交互是否应依赖正文或材料变化后仍能持续、精确定位原文？

## Answer

2026-10-13，用户指出持续精确原文定位难做且不可靠，要求所有依赖此能力的功能现阶段都不考虑，并确认以下范围。

### 当前排除的功能

凡依赖内容变化后仍能持续、精确定位原文的功能，现阶段均不纳入设计。包括正文与证据的持续逐句关联、随编辑自动跟踪的审阅批注、段落移动或改写后的自动重定位，以及依赖这些能力的原位状态提示。也不以“先尝试重定位，失败再提示”的方式保留这一要求。

这是一项范围约束，不是等待实现验收的功能承诺。是否重新讨论由后续实际需要决定，当前不安排实现。

### 保留的交互

- 当次选择：将当前选中的文字或图片区域交给 Agent。
- 核查记录：保存当时的摘录、来源与分析，作为可独立阅读的报告。旧记录不自动成为对新正文的判断。
- 普通来源访问：打开文献或文件；有可靠页码时跳到对应页面。固定材料版本上的阅读、书签与批注沿既有能力处理，不要求跨内容变化保持精确位置。
- 重新核查：需要时让 Agent 读取当前材料重新判断，不假设旧关联仍然有效。

工作台围绕材料、报告、稿件和修改结果提供交互。证据、主张、审阅意见与稿件仍可在对象及记录层面关联；查看差异和处理意见不依赖持续跟踪正文位置。

### 与普通编辑的边界

Agent 编辑前重新读取当前文件、核对修改范围，以及撤销前保护后续编辑，仍是必要的读写行为。当次操作依据当前内容判断能否应用，无法可靠确定时保留内容并报告问题，不要求长期维护段落身份或历史位置映射。文件移动后的路径重新指定不属于本票排除的原文定位功能。
