## Question

首阶段需要哪些稳定研究对象，它们分别属于长期文献库、具体研究项目还是执行会话？文献、自己的研究材料、证据、主张、稿件、修订问题、决策与候选产物应如何关联、命名和确定权威来源？

研究任务的持续身份和跨会话延续要求已由[Agent 一等公民约束](02-agent-first-contract.md)确定，词义见 CONTEXT.md。本票继续明确其与来源、稿件、决定等对象的关系及所有权。

检验同一文献跨项目承担不同角色、引文与证据支持关系不同、分析结果可重用但项目结论有条件等情境。明确稳定内部身份与 DOI、Zotero key、citekey 的关系。结合兼容选择检查旧插件是否依赖特定数据形态，但不要让兼容细节代替领域定义。此票明确语义和所有权，存储实现交给存储票。

## Answer

用户在两轮讨论中分别回复“全部采纳”，本票于 2026-10-03 解决。以下对象与关系是科研 Agent 内核可以直接查询、关联和修改的资源；工作台负责呈现与人的介入。术语定义统一保存在 [CONTEXT.md](../../../CONTEXT.md)。

2026-10-04 按用户确认的[低摩擦协同方案](13-storage-and-change-model.md)，来源与判断的归属保留，定位及留存按实际研究用途处理。

### 来源的范围与身份

- 来源覆盖文献和自己的研究材料，包括实验数据、记录、代码、计算结果和图件，保留各自的类型。
- 来源具有稳定内部身份；DOI、Zotero key、citekey 和文件路径作为标识映射或属性。材料及其版本另行区分，证据指向实际使用的版本。
- 预印本与正式发表版显式关联，去重应保留差异。
- 普通文件可以直接操作，Agent 在分析、引用或复用材料时可以建立来源记录。同一计算结果可以同时作为任务产物与后续任务来源。

### 分析成果的归属与跨项目复用

- 文献元数据、附件、批注，以及不依赖具体项目假设的精读和综合成果，可以归长期文献库。
- 来源在当前研究中的角色、相关性评价、证据选择和研究结论，归具体项目。
- 项目采用已有分析时保留必要来源与条件；关键证据及重要成果保留实际版本。新分析在相关工作中按需呈现，已有正式判断按授权明确更新。
- 项目成果可以被主动整理为跨项目知识，保留其最初成立的条件。

### 渐进管理研究主张

- 研究主张是一等研究对象；Agent 优先提取核心贡献、关键结论、定量表述和有争议的判断，关联依据、适用条件、结论强度与不确定性。
- 支持直接编辑正文，再由 Agent 补充关系，无需逐句手工建立结构化记录。
- 候选观点、待验证假设与已确认主张明确区分，均可长期保存和继续讨论。进入正式研究承诺时遵循已确认的授权与确认规则。

### 项目、稿件与任务产物

- 一个项目可以拥有多份稿件，每份稿件有自己的结构、版本、投稿目标和审稿轮次。
- 来源、证据和研究成果可以共享；具体稿件采用哪些主张及如何表述，由该稿件的关联记录表达。
- 审稿意见和回复绑定相应稿件及版本。
- 研究任务可以关联多份材料和产物。任务结束、会话关闭或更换 Agent 后，对象仍属于项目或文献库，可以继续使用。

### 证据与主张的关系

- 证据定位到具体材料版本的原文片段、观测或结果，保留位置、上下文、提取方式及核验情况。
- 支持、冲突和限制属于证据与主张之间的关系，并记录判断理由和适用条件。证据本身可以复用，是否足以支持当前主张需要结合项目判断。
- 论文之间的引用关系另行表达。找到相关文献、核对原文、确认其支持某个结论，是不同的工作进展。

### 主张在稿件中的表达

- 主张关联稿件的具体位置；一个主张可以对应多处表述，一段文字也可以涉及多个主张。
- Agent 修改文字时区分表达修改与论证修改。表达修改保护数值、引用、条件和结论强度；论证修改明确判断变化及受影响的关联表述。
- 日常稿件关联按需定位到当前内容；重要交付与审稿轮次关联留存版本。段落移动、重写或拆分后先尝试重定位，仍有歧义时在相关工作中提示核验，不要求每次编辑先检查全部关系。
- 继续采用渐进方式，优先覆盖关键内容。

### 问题、变更与正式决定

- 待解决问题记录审稿意见或研究中发现的问题、涉及对象及解决标准。
- 需要审查或明确跟踪的变更记录修改内容、依据和处理情况；普通授权编辑使用差异、撤销与本地历史。
- 正式决定记录选择、理由、授权主体及影响范围，沿用[Agent 一等公民约束](02-agent-first-contract.md)确定的授权规则。
- 问题、变更和决定可以多对多关联，并关联所需研究任务。
- 接受方案后仍需完成实际工作并核验。回复中声称补充的实验或稿件修改，应能找到对应结果与版本。

### 领域权威与派生视图

- 研究事实、执行状态和派生视图分别表达，每个概念只有一处权威定义。
- 研究任务关联来源、主张、稿件与决定；会话和执行记录关联任务及相关对象。
- 已确认的研究决定、身份绑定和合并结果需要长期保存，缓存重建保留这些事实。
- GUI、Agent 接口和复用组件通过共同契约访问这些事实。
