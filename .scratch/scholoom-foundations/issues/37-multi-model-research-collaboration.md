### Q1：复用原生内容组织角色配置

在已确认能力／工作流的原生内容中保存可复用角色配置，引用共同方法与命名模型配置，支持用户或项目派生和任务覆盖，不另建同名协作流水线。模型选择、发送授权与执行上限沿已有模型政策。

| 职责 | 业务配置与交付 |
| --- | --- |
| 主 Agent | 组织研究工作、分派具体任务、汇总意见及安排修改，沿实际产物核对交付。 |
| 执行者 | 承担起草、分析、补充验证或修订，使用对应能力与方法，交付实际成果。 |
| 学术审阅者 | 配置审阅视角与标准，如研究设计、论证与证据、文献与引用；同一角色可按不同视角实例化，交付可定位意见与依据。 |
| 文风监督 advisor | 配置目标语言、文体与相关方法，显式开启／关闭；开启后共享当前写作上下文，在 Agent 生成文本后向写作 Agent 注入去 AI 化修改建议，由写作 Agent 继续修改。 |

角色配置不固定具体模型品牌，不预设每次启用全部角色；本轮细化可复用配置的组成，具体委派仍按研究工作安排。

### Q2：学术分工审稿的独立初审与统一应用修改

学术分工审稿默认先让各审阅者依据稿件、研究材料和审阅标准分别形成意见，首轮不预先输入其他审阅者意见或主 Agent 的拟结论。已有研究条件、证据与作者明确约束仍可读取。后续需要讨论或复核时，再提供已保存意见及其依据。

审阅者将报告和候选修改保存为工作区产物，默认不直接修改被审稿件；主 Agent 汇总、安排获授权执行者应用修改与必要复核。此为审阅职责预设，可在具体工作包中明确委派修订职责。意见保留作者角色、模型、实际材料与定位，记录处理理由与实际修改关联，不能用汇总替代原意见或以多数票确认研究结论。普通获授权修改沿已有低摩擦机制应用，不增加逐项人工审批。

### Q3：文风 advisor 的处理对象

文风支持面向 Agent 生成文本的去 AI 化润色，由 advisor 提供修改建议、写作 Agent 继续修改。用户自行撰写或修改的内容不因保存而进入自动文风处理；相关文本可作为理解文体与语义的上下文读取。既有持续参与与阶段性集中处理的需求均沿此对象范围，通过 advisor 的写作过程参与及针对阶段性生成成果的评审组织。

文风 advisor 与学术分工审稿分别组织，实际文件修改沿任务授权和共同写入机制。

### Q4：写作过程中的可开关 advisor

用户要求借鉴 omp advisor 的角色设计。文风监督作为写作过程中的 advisor，由用户显式开启／关闭；开启后取得当前写作 Agent 的上下文，在生成文本后注入修改建议，使写作 Agent 结合原有研究条件继续修改。业务接线沿下方 Q5；具体上下文构造、触发标记与消息机制由 harness 协作票承接。

共享当前执行上下文用于当次协作，跨会话科研承接仍使用已保存的研究材料与事实。处理对象沿生成操作明确，作者身份不能由文风检测猜测。材料发送权限沿已有模型政策落实。

### 材料、用户介入与续做的既有契约

工作包沿原生内容契约提供目标、实际文本引用、所需材料、写作约束、授权和交付要求；角色按授权继续发现与读取材料，科研承接使用工作区已保存内容。稿件、学术审阅意见、advisor 建议和实际修改等科研产物与处理依据按工作区契约保存；实际交付及进展依据产物和检查。

用户可沿 Q1 和模型政策调整角色配置、模型及本次工作安排，查看各角色产物和实际修改。中断后保留已完成材料，继续未完成工作，应用前核对当前目标；模型不可用、取消、重试与显式切换沿模型政策执行，不静默替换模型。advisor 中断与注入行为沿 Q5，工作台呈现由工作台票承接。

### Q5：advisor 的上下文与建议注入

advisor 开启时取得当前有效写作上下文与约束，后续接收新增生成文本、材料读取结果和相关写作变化，沿已授权工具继续读取。以生成文本完成的执行边界组织评审，不按逐字输入调用；advisor 的当前读取范围可以包含用户材料，提出文风建议的目标仍限定为 Agent 生成文本。

advisor 使用自己的文风方法和已配置模型，通过独立建议消息向写作 Agent 提供定位、理由和可用改写；默认授予读取与建议提交工具。写作 Agent 结合研究依据处理建议并实际修改，对事实、引用、数值、限定和结论强度负责。建议、处理理由和实际修改按工作区契约保存，无建议时保持静默。

过程中后台评审，建议在可消费的执行边界进入写作上下文；写作 Agent 准备结束本轮时有限等待已触发的 advisor 评审。收到具体修改建议后可在原任务中继续修改；advisor 引起的继续默认不重新触发同一轮监督，避免建议循环。等待超时或模型失败如实保留状态与已有成果，后续行为沿模型政策，不声称已经完成文风监督。用户关闭 advisor 或主动停止后停止新增监督与自动继续，关闭后尚未注入的建议保留供查看。
