## 本轮已确认的交互方向

用户已确认选区旁与 Agent 面板共用指令、图表对象选择与普通图片区域标注。

用户随后确认了原位与任务中查看结果和依据、撤销变化通知与后续编辑保护、审阅意见关联实际修订和回应的方向。正式结论集中在决策票 Answer；用户尚未人工操作原型，实际图形体验与运行效果仍待验证。

## 代表性走查

| 场景 | 操作 | 观察重点 |
| --- | --- | --- |
| 稿件局部修订 | 在稿件中选中文字，或点“选中结论句”；就地写指令，点“到 Agent 面板补充”，附加文献依据。发送后点“演示结果”。 | 两个输入区共用草稿；目标、依据、接收者分别显示。修改直接应用，原位可看差异、理由与依据。 |
| 切换材料 | 附加稿件目标后，切到分析报告并点“附加作为依据”，再回到稿件。 | 浏览不替换已附加目标；报告作为辅助材料。选取报告文本也可给 Agent 单独指令。 |
| 图表对象修改 | 打开图 2，点击纵轴标题或图例，发送预置指令并演示结果；打开生成来源。 | 图表预览与生成来源一起体现示例修改。子图 A 可作为分析目标。 |
| 普通图片标注 | 切到普通图片，在图中拖动框选；也可点“标注右上区域”。发送并演示结果。 | 记录区域和图件引用；尚未识别可编辑元素时如实显示。移除待发指令中的目标标签，不消除图片上的区域标注。 |
| 手工编辑与撤销 | 发稿件修订指令，先改“作者补充”，再演示结果。修改应用后可在结论末尾追加说明，再撤销修改。 | 无关段落与追加内容保留。撤销通知出现在原任务，示例没有自动重做。 |
| 同处编辑 | 指令发出后重写被选结论，再演示结果；或应用后重写目标，再撤销。 | 原型保留当前文本，仅提示这一处需要协调；不能把该提示机制作为生产环境通用重定位实现。 |
| 审阅意见 | 重置示例，打开审阅意见，点“交给主 Agent”，发送并演示结果。 | 保留不同审阅角色的原意见；正文与回应分别可查看、撤销。修改已应用不等于意见已解决，示例停留在回应待核对。 |
| 从任务找回 | 收起 Agent 面板，打开“任务与产物”。 | 能找到示例修改、区域记录与报告分析结果；文风 advisor 可开关，但没有真实评审运行。 |
| 源码与正文 | 在稿件页切到源码，修改结论段，再切回正文。 | 两个入口使用同一段内容。此示例不解析完整 QMD，不验证学术语法与格式保真。 |

## 已执行的检查

2026-10-09：用 Node `vm.Script` 检查内联脚本语法；Playwright 在浏览器内存中加载同一 HTML，通过 18 项代表性行为检查，覆盖输入同步、材料保持、局部应用／撤销、源码与正文一致、重叠编辑保护、图表目标与生成来源、真实拖动框选、区域与指令标签区分、任务找回分析结果、advisor 开关和审阅回应关联。浏览器未报告脚本错误。另查看 1440×1000 下的图表对象选择截图。

新增报告选区共用处理后，另核对稿件与报告实际文本选区能够打开相应就地指令。以上为示例行为检查，不作为生产实现或用户体验验收。

## 局限

- 材料、研究任务、角色与修改均为合成示例；“演示结果”应用固定候选，不根据自由指令调用模型。
- 状态仅保存在页面内存。源码、图表生成程序、任务记录没有真实落盘；版本号是示例内容变化计数。
- 稿件只有结论与作者补充两段。位置采用固定段内偏移；段落移动、复杂编辑节点、多文件工程及真实并发需要正式编辑组件和既有定位契约。
- SVG 标注修改直接更新示例预览；没有运行 Python、分析计算或图表重生成。普通图片区域没有自动识别语义或匹配到生成代码。
- 交流仅呈现最近 8 条指令，修改卡片最多呈现最近 12 项，活动最多呈现最近 5 条；没有实现生产检索或分页。正文输入不重建整个页面。
- 未接入真实 PDF、QMD／LaTeX 渲染、持久化、权限、内核、模型或 advisor；未验证科研正确性、延迟、长期性能、三平台和辅助技术完整支持。

按用户的 Git 操作边界，原型保存在当前讨论材料目录，未建立研究分支或提交；本票不把临时草图转为业务实现。
