# 科研事实归属与项目可搬迁：情境核对

> 辅助草稿：由子 Agent 生成，未纳入本轮决策依据。宏观产品、领域模型和架构判断以主对话及已确认决策票为准。

依据已确认的[领域边界](../issues/06-research-domain-boundaries.md)、[能力模型](../issues/17-native-research-capability-model.md)、[运行时契约](../issues/18-native-capability-runtime-and-content.md)、[存储票（claimed）](../issues/13-storage-and-change-model.md)及本次用户纠正。本文是语义情境核对，不是运行验证；Q3 外部编辑、Q4 Git/历史搁置。

| 情境 | 对象与关系的 owner | 出处、适用条件与核验范围 |
| --- | --- | --- |
| 论文结论抽取 | 论文拥有其主张及文内依据；项目拥有“支持本项目判断”的关系 | 抽取核验只确认论文确实这样说，不确认其为真；记录版本、位置及核验范围。 |
| 同一证据用于 A、B | 证据定位到来源版本；A、B 分别拥有其与主张 X/Y 的支持、冲突或限制关系 | 各自保留条件和理由，A 的判断不随证据全局化。 |
| 自有实验与结果 | 材料、版本、观测证据及主张归产生它的项目 | 记录实验条件和出处；算完或写入稿件不等于结论已确认。 |
| 项目成果跨项目复用 | 原项目保有原主张；经整理形成的共享知识才归全局 | 保留来源项目、版本、成立条件及核验范围；引用次数不构成升级。 |
| 项目脱离文献库 | 项目拥有本地关系及所需来源身份、版本和引用快照；文献记录仍属文献库 | 搬迁内容须足以读懂出处与判断条件。全局查询不要求一个全局可写数据库；文献全局事实写入数据库，具体设计待定。 |
| 文献版本更新 | 文献拥有当前已知版本事实；旧版材料/定位是历史快照，项目拥有其判断关系 | 新版不静默改写旧引用或判断；受影响关系需按新版重核。 |

“全局”指跨项目范围，不意味着所有 Evidence、Claim、关系都归全局文献对象。文献主张属文献；稿件主张及论证关系属项目。关联记录不因此成为新科研概念，也不预设新领域类型。

待用户决定：独立项目需携带的最小文献快照范围；文献出新版后只提示重核还是显式更新。成果升为共享知识须经整理/核验，权限与确认方式待议。全局权威不等于始终可访问的单一数据库实例。
