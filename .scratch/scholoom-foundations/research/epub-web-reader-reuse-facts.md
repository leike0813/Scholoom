# EPUB 与网页阅读可复用模块：源码核验事实

核验日期 2026-10-04。只读克隆三份上游源码，未构建、未运行、未安装依赖；以下均为静态读码结论。epub.js 固定于 [`eee359d`](https://github.com/futurepress/epub.js/tree/eee359d0790002115a1156a9833c54f4bcd44c1d)（v0.3.93，2026-03-23），foliate-js 固定于 [`78914ae`](https://github.com/johnfactotum/foliate-js/tree/78914aef4466eb960965702401634c2cb348e9b1)（2026-05-01），zotero/reader 固定于 [`692c289`](https://github.com/zotero/reader/tree/692c28989629acf920fadb683747e18e5506b214)（2026-10-01）。

## epub.js：引擎，无 UI，搜索只到单章节

- `src/` 只有解析、rendition、CFI、位置、注释、主题等模块（[epub.js/src](https://github.com/futurepress/epub.js/tree/eee359d0790002115a1156a9833c54f4bcd44c1d/src)）；阅读器 UI 只以 `examples/*.html` 形式存在，库本身不含工具栏、侧栏、批注面板。TypeScript 类型在 `types/*.d.ts`（[types](https://github.com/futurepress/epub.js/tree/eee359d0790002115a1156a9833c54f4bcd44c1d/types)）。
- 搜索粒度是 **Section**：`search(_query, maxSeqEle = 5)` 用 TreeWalker 以 5 个文本节点为滑动窗口，每窗只取 `indexOf` 的首个匹配，返回 `{cfi, excerpt}`，excerpt 上限 150 字符（[section.js#L185](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/section.js#L185)）。`src/book.js` 没有对应聚合搜索方法（[book.js](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/book.js)），跨章节搜索、结果计数、跳转高亮需自建。
- 定位基础设施可用：`EpubCFI` 可由 Range、Node 或 CFI 字符串构造并 `toString()`、`compare`（[epubcfi.js#L25](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/epubcfi.js#L25)）；`Locations` 提供 `generate(chars)` 与 `locationFromCfi`、`percentageFromCfi`、`cfiFromPercentage`（[locations.js#L316](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/locations.js#L316)、[#L387](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/locations.js#L387)），但 `generate` 会遍历加载全部 spine section。
- 注释与选区：`rendition.annotations` 为内置实例（[rendition.js#L112](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/rendition.js#L112)），支持按 CFI 挂载/摘除 mark（[annotations.js](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/annotations.js)）；选区以 `selected` / `selectedRange` 事件外抛，无内置选择工具栏（[utils/constants.js#L13](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/utils/constants.js#L13)、[rendition.js#L901](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/rendition.js#L901)）。主题注入在 [themes.js](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/src/themes.js)。
- 许可 `BSD-2-Clause`，见 [package.json](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/package.json) 与 [license](https://github.com/futurepress/epub.js/blob/eee359d0790002115a1156a9833c54f4bcd44c1d/license)。

## foliate-js：搜索/覆盖层/CFI 可单独取用，UI 与库明确分离

- 模块化原生 ES module，`exports` 为 `"./*.js"`，无构建步骤（[package.json](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/package.json)；README 称 “no build step”，见 [README](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/README.md)）。README 同时声明 `reader.html`/`reader.js`/`ui/` **不属于库**，需自行修改或替换。
- 搜索可独立复用：`search(strs, query, options)` 适用于任意字符串数组；`searchMatcher(textWalker, opts)` 返回生成器，支持整词、大小写、变音敏感度（[search.js#L103](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/search.js#L103)、[#L111](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/search.js#L111)）。README 明说该实现 “extremely slow”，应增量加载结果；配套 `text-walker.js` 负责文本节点与 Range 互转。
- 注释呈现为引擎级 SVG 覆盖层：`Overlayer` 由渲染器的 `create-overlayer` 事件注入，只有 `hitTest({x, y})` 命中测试，默认无事件（[overlayer.js#L4](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/overlayer.js#L4)、[#L41](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/overlayer.js#L41)；README 说明这是 marks-pane/Epub.js 同类技术）。
- 定位：CFI 解析为 `{index, id, offset, temporal, spatial, text, side}` part 数组，`fromRange`/`toRange` 支持忽略自有节点（[epubcfi.js](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/epubcfi.js)；README “EPUB CFI” 一节说明 spatial/temporal/text 断言可解析但渲染时尚未使用）。`view.js` 的 `goTo(target)` 接受 path、section index 或 CFI（[view.js#L460](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/view.js#L460)），`relocate` 事件给出 `{range, index, fraction}`。
- 耦合点：分页器用 CSS 多列，README 承认同样慢、不支持连续滚动、**没有 CFI 概念而直接操作 Range**（[README 渲染器一节](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/README.md)）。EPUB/CBZ 读取需要外部 zip loader 实现 `entries/loadText/loadBlob/getSize`，README 推荐 zip.js 随机访问；`view.js` 自带实现，含 SHA-1 去混淆字体依赖 Web Crypto 限制。PDF 适配器被 README 明确称为 proof-of-concept、实验性（主 PDF 已定 EmbedPDF，本次不涉及）。
- 许可 `MIT`，[LICENSE](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/LICENSE)。`package.json` 版本为 `0.0.0`，README 自述 API 不稳定、建议以 submodule 引入。

## Zotero reader：EPUB 与网页快照共用同一批 DOM 注释/搜索代码

- EPUB 视图用的是 Zotero 自己的 epub.js fork，而非上游（[.gitmodules](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/.gitmodules) 指向 `https://github.com/zotero/epub.js.git`；[epub-view.ts#L16](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/epub/epub-view.ts#L16) `from "epubjs"`）。本次未初始化子模块，未核对该 fork 与上游的差异。
- **网页快照可复用同一套 DOM 阅读/批注层**：`abstract class DOMView`（[dom-view.tsx#L81](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/common/dom-view.tsx#L81)）用 `toSelector`、`toDisplayedRange`、`navigateToSelector`、`getAnnotationFromRange` 抽象出与格式无关的注释接口，注释 position 直接取自 `toSelector(range)`（[dom-view.tsx#L1455](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/common/dom-view.tsx#L1455)）。EPUB 实现返回 EPUB CFI 的 `FragmentSelector`（[epub-view.ts#L432](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/epub/epub-view.ts#L432)）；快照实现返回 `CssSelector`，选区不足整元素文本时用 `TextPositionSelector` 精化，唯一选择器生成失败时退化为 body 上的 TextPositionSelector（[snapshot-view.ts#L395](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/snapshot/snapshot-view.ts#L395)）。三种 selector 类型即 Web Annotation Data Model 子集（[selector.ts#L4](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/common/lib/selector.ts#L4)）。
- 搜索同样共用：`DefaultFindProcessor` 把文本节点压平为字符串上下文，在 Web Worker 里做正则匹配（整词/大小写），返回字符区间再还原为 Range（[find/index.ts](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/common/lib/find/index.ts)、[find/worker.ts#L7](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/common/lib/find/worker.ts#L7)）；`EPUBFindProcessor` 只负责跨 section 轮转渲染器（[epub/find.ts#L11](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/epub/find.ts#L11)）。快照视图同样使用 `DefaultFindProcessor`（[snapshot-view.ts#L33](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/snapshot/snapshot-view.ts#L33)）。
- 快照视图构造点与 EPUB 视图同在 reader 核心（[reader.js#L2206](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/common/reader.js#L2206)），web 入口 `createReader` 走同一内核。许可 `AGPL-3.0`（[package.json](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/package.json)），与 Scholoom 项目许可一致，但复用即继承 AGPL 义务。

## 源码提取 vs 公开独立库的边界

- 可按独立库直接引入：foliate-js 的 `search.js`、`text-walker.js`、`overlayer.js`、`epubcfi.js`（MIT，单文件 ES module，无构建）；epub.js 整包（BSD-2-Clause，需构建或走 `lib/`）。
- 只能源码提取：Zotero 的 selector↔Range 转换、DOMView 注释抽象、worker 搜索（`src/dom/common/**`），它们没有独立发布包，且整体受 AGPL-3.0 与 Zotero 商标/第三方版权声明约束。
- UI 与引擎分别评估：foliate-js 的 `reader.html`/`ui/`、epub.js 的 `examples/` 是示例／应用界面；Zotero reader 的 React 组件与 DOM 阅读层共同提供批注和选区交互，可随相关源码成组吸纳，但没有独立发布的通用 UI 包。其 web 入口和宿主保存回调见 [已有宿主接口调查](reading-and-annotation-boundaries.md)。

## 复用时的已知耦合

- Zotero 两个 DOM 视图都直接依赖 `structured-document-text` 子模块的类型与 `src/common/sdt/position-mapper`（[epub-view.ts#L15](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/epub/epub-view.ts#L15)、[snapshot-view.ts#L43](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/snapshot/snapshot-view.ts#L43)）。要单独抽出 `src/dom/common/lib/**`，必须同时处理这些 SDT 依赖，否则拿到的不是完整可运行的 DOM 阅读层。
- 快照视图还内嵌 darkreader 与 webpack `raw-loader` 引入（[snapshot-view.ts#L35](https://github.com/zotero/reader/blob/692c28989629acf920fadb683747e18e5506b214/src/dom/snapshot/snapshot-view.ts#L35)），说明该文件不是设计上可独立分发的模块。
- foliate-js 的 `progress.js` 提供 `TOCProgress`、`SectionProgress`（[progress.js#L18](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/progress.js#L18)），但它按“book 接口”取值（`splitTOCHref`、`getTOCFragment`），替换 EPUB 引擎时进度模块需要跟着换实现，而不是通用组件。
- epub.js 与 foliate-js 的分页器都有 CSS 多列机制，但内部对象和生命周期不同。两者均提供 EPUB CFI 能力；foliate 的底层分页器操作 Range，不代表其整套阅读层没有 CFI。跨引擎位置往返需验证注入节点、文稿版本和路径处理，不从内部表示差异推断标准 CFI 必然不兼容。

## 固定点与未实测

- 固定点：三份源码 commit 已在上文列出；所有结论仅为静态读码。
- 未实测：渲染性能、搜索速度（foliate 自述极慢、epub.js 单节窗口搜索的实际表现）、CJK 分词与整词匹配、快照 DOM 变化后 CssSelector/TextPositionSelector 的重锚定成功率、EPUB 脚本文本在 Electron CSP 下的行为、zotero/epub.js fork 的具体改动、任何 roundtrip 保存。
