# main 与历史版本的 Synthesis TS 计算恢复价值

本次只核对已有 Git 对象中的计算、产物和直接调用。用户已确认先用 TypeScript；本文不选择新图库，也不承担 service/repository/library 的完整宿主耦合审计。源码均经 `git show <SHA>:<path> | nl -ba` 读取，main 证据没有使用只索引 dev 的 CodeGraph。

固定基线：local main 为 `fe273f37f2093c4a34be15f93e7d46a3b3484791`（下文 M），本地 origin/main 为 `2b2b540f54fbb5495e17b275530454ca6d808d5a`（O），dev 为 `8394fee1a8708a0c2a04e786f6fd8c47f1f28f33`（D）。四个目标文件及 yield helper 在 M/O 的 blob 相同；`git diff M O -- src/modules/synthesis packages package.json` 无差异。因此下面 M 的文件行号也适用于 O。主任务于 2026-10-03 通过只读 `git ls-remote` 核实远端 main 同为 O，详见[main 应用调查](synthesis-typescript-main-application.md)。已读取两个 main 基线的 AGENTS.md。

**main 有完整 TS 布局，而且当前调用直接执行这份实现。** [M citationGraph.ts:1043](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/src/modules/synthesis/citationGraph.ts#L1043) 按算法分派到 force、radial、components 的实际函数。force 创建 Graphology 图及 d3-force simulation，安装 link、charge、collision、center，先 `.stop()`，随后在同步循环内执行 700 次 `tick()`；连通节点计算完后，孤立节点另行摆放。[M citationGraph.ts:1163](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/src/modules/synthesis/citationGraph.ts#L1163) 是算法正文，700 来自同文件 174 行的参数。radial 按度数等规则排序后用螺旋和引用源中心放点；components 建无向邻接、遍历连通分量，再按网格和螺旋放点，分别见同文件 1257、1320 行。现有依赖为 `d3-force ^3.0.0`、`graphology ^0.26.0`，见 [M package.json:122](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/package.json#L122)。

main 的直接入口是 `recomputeCitationGraphLayout`，在 `lock.runExclusive` 的回调里调用同步 `computeCitationGraphLayout`，随后才把结果 `JSON.stringify` 并交给持久化方法。[M service.ts:17922](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/src/modules/synthesis/service.ts#L17922) 证明这条路径不是凭函数名推定的 Rust/HTTP 布局。该入口的预算检查在调用前（17894 行），布局函数没有中途时间检查；不能把诊断里的 “worker” 一词当作实际线程证据。

**计算函数与宿主依赖的分离程度不同。** main citationGraph/referenceMatcher 的函数体使用普通数据，但都导入 `foundation` 的 hash helper；[M foundation.ts:1](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/src/modules/synthesis/foundation.ts#L1) 同时导入 persistence、repository 等模块，不能据函数体把整个导入闭包称为环境无关。conceptKb/topicGraph 直接在同一文件组合 repository 读取、投影计算及 rebuild 记录。图、布局、指标各有独立产物 hash，计算本身不写库；调用方另作结果 promotion。这足以识别计算与产物边界，完整权威归属仍由父任务核查。

**main 有真实 yield 接线，但没有覆盖长计算内部。** [M runtimeCompatibility.ts:56](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/src/utils/runtimeCompatibility.ts#L56) 的 `yieldToEventLoop` 明确等待 `globalThis.setTimeout(resolve, 0)`。service 在概念/主题 rebuild 分别传入它（[M service.ts:18847](https://github.com/leike0813/zotero-agents/blob/fe273f37f2093c4a34be15f93e7d46a3b3484791/src/modules/synthesis/service.ts#L18847)、18874 行）；下游在整组读取、排序和 projection 构建之间 `await yieldControl`。匹配调用者每处理 25 条报告一次进度，报告会 yield（service 12390、12248 行）；索引构建及一次完整 clustered dedupe 则直接同步调用（12256、12437 行）。指标报告在计算前 yield（14368 行），真正计算仍是 8010 行的同步调用。布局 700 ticks、PageRank 50 轮、排序、hash/JSON 和索引内部没有这些让出点。

**历史中存在接口更完整的 TS 抽取版本。** 定向 `git log -5` 后核对 H=`57c298619fae801a58e909de3b663c6a41dd37c5`，它是 `0adb1ab1a06768bf3c14db6c20e32d89231ac954` 的父提交。H 的 [engine/index.ts:733](https://github.com/leike0813/zotero-agents/blob/57c298619fae801a58e909de3b663c6a41dd37c5/packages/synthesis-engine/src/index.ts#L733) 实现三种布局、请求/结果校验和 engine 接口；force 正文在 523 行，初始坐标由 DTO 提供，不导入 main 的 foundation，也没有 Graphology import。该版布局上限为 5000 节点、20000 边。逐 tick checkpoint 是 `=> void` 同步调用，async facade 只是包装，并无真实 yield。

H 已有三种布局坐标/hash 观察用例与 Node Worker canary；后者只测 components 请求直接计算与 Worker 结果相等，见 [H test:243](https://github.com/leike0813/zotero-agents/blob/57c298619fae801a58e909de3b663c6a41dd37c5/test/core/183-synthesis-citation-graph-layout-engine.test.ts#L243)、319 行。本次仅查读，未运行，也不将它当作当前可执行性、规模或取消保证。D 的 [index.ts:231](https://github.com/leike0813/zotero-agents/blob/8394fee1a8708a0c2a04e786f6fd8c47f1f28f33/packages/synthesis-engine/src/index.ts#L231) 已要求 forceatlas2-rust/radial-rust/components-rust 与布局版本 2，不能把 H 的 d3-force 1.2 结果直接交给该 validator。

恢复候选需自主验证：旧/新 DTO 与版本映射；初始坐标、排序及 hash 对输出的影响；分块预算和身份归一化语义；现有依赖在目标构建中的可执行性；目标输入上的响应时间及内存；取消机制。单个 Worker 的长同步循环不会处理中途普通 cancel 消息，checkpoint 的存在也不证明共享 flag 已接线。本次没有实验或性能倍率结论，停止于候选和这些验证边界。
