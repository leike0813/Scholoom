## Answer

2026-10-20，用户分两轮采纳本票建议，确认以下校准路径、实际交付与三域交接，作为后续领域设计的共同输入。本票确定首条路径的范围，线上获取、独立库综合及完整科研流程继续沿已有产品要求推进。

### 校准路径与输入

从已有共同文献库开始，在项目中围绕一个研究问题开展定向综合。样例指令由用户明确要求建立一项持续研究任务，说明研究目的和必要约束；任务不成为普通问答或一次方法使用的自动产物，沿[既有会话与任务约定](../../scholoom-foundations/issues/43-free-agent-conversation-and-research-tasks.md)处理。

Agent 从指定或获授权的库范围渐进取材，按目的发现并读取题录、可复用分析和原文。包含全文缺失等部分材料可用情境，保持已知材料条件可辨。采用哪些文献、读到何种深度及如何组织综合由科研工作需要决定；内容与方法沿既有分层知识及成熟分析实践细化。

首个样例不以线上发现、筛选、收录和全文下载全部接通为前置。线上获取与独立库主题综合保留各自的设计入口。

### 实际交付

| 交付 | 可检查的结果 |
| --- | --- |
| 项目定向综合报告 | 保存比较发现、来源依据、适用条件和缺项，能通过已有文档视图查看、核查与编辑。 |
| 实际来源与材料关联 | 能辨认实际采用的文献、材料版本及分析成果，并沿引用继续读取；只有题录或缺少原文时如实说明材料条件。 |
| 持续研究过程与任务进展 | 在形成时保存有接续价值的分析、采用理由、限制、已知问题与下一步，关联实际成果；任务进展可独立查询。 |

报告正文与研究过程沿已有开放文件规则保存，所属结构化事实由相应领域管理。过程记录保留足以继续研究的内容，概览或交接摘要不替代完整依据，沿[工作区承接决议](../../scholoom-foundations/issues/35-research-workspace-context.md)执行。具体目录、格式、对象字段与关联操作由领域设计确定。

首条路径使用已有文档视图承接报告。交互式报告的通用能力继续由成果交互域细化，不作为此次路径校准的前置。

### 最小跨域交接

| 责任方 | 提供与掌握的内容 | 与其他域的交接 |
| --- | --- | --- |
| 文献与知识管理 | 稳定文献身份、附件与材料版本、可读内容、库内可复用分析及其材料条件 | 向方法与项目提供可发现、可读取、可引用的实际来源；库内成果继续保有自身归属。 |
| 科研方法与工作流 | 按研究目的组织分析与综合，定义并检查实际交付 | 消费材料及成果引用，将报告和实际采用依据交回所属领域；方法执行不另建领域权威。 |
| 研究项目与研究资产 | 项目目标、持续任务、采用理由、研究过程、成果关联和下一步 | 引用库来源，保存当前研究语境下的判断与成果，供后续工作发现和读取。 |

三域需要先对齐来源与材料版本引用、成果及过程的保存和读取、任务与能力调用的关联，以及部分完成结果的表达。具体 DTO、Schema 和操作名称在后续设计中细化，沿共同 protocol 与 broker 接入。现有 Agent 库读取工具和项目文件能力可以复用；显式科研能力接受库材料引用、库级分析成果持久接口仍需设计，不能按已经具备处理。

会话、执行尝试、能力调用和研究任务继续保持各自语义。通用 harness 提供执行与接续机制，领域保存事实；会话记录不承担研究承接权威。

### 补充材料与新会话续做

首次交付后加入或补齐一篇文献，由用户在新会话明确要求继续研究。接续者应能从工作区和所属记录找到研究目的、已有成果及依据，辨别实际新增或补齐的材料，判断其对当前综合的影响，并保存更新理由与实际后续成果。

校准检查实际研究能否继续，包括已有依据是否正确采用、材料变化是否被识别、更新是否落实；不以能打开旧报告或读取一段交接摘要替代承接质量。

材料缺失、分析部分完成、取消或更新失败沿既有渐进可用与成果保护约定办理：保留实际成果和障碍，区分执行、交付与科研判断，不凭模型自述报告完成。库分析与主题维护沿原决议；闲置项目只保留影响线索，恢复时由用户手动启动复核，沿[跨模块走查决定](../../scholoom-foundations/issues/42-cross-module-research-walkthrough.md#q1-已确认无人工作的项目受到库更新影响)。

### 后续设计与验证边界

文献知识、研究项目资产、科研方法三域据此分别确定职责与首批详细设计范围；Agent、科研计算及成果交互域据此判断需要支撑的能力和启动条件。当前票中的分工是最小协作输入，不替代各域职责票或授权业务实施。

本轮只做讨论、接口静态核对和决策记录。真实材料样本、具体研究问题、科研质量评价及整合运行证据在后续设计和验收中落实；不从本票解决推导路径已经实现。
